# 项目架构

## 设计定位

| 维度 | 说明 |
|------|------|
| **是什么** | 应用运行时 + 应用商店 + 版本仓库的整套方案 |
| **不是什么** | 不是容器运行时（无 namespace / cgroup 隔离），不是包管理器（不替代 pip / npm） |
| **核心价值** | 最小依赖 + 最小协议（`app.json`），管理多语言应用的部署 / 增删 / 升级 |
| **目标平台** | Windows / Linux / macOS / ARM 嵌入式（树莓派、Jetson 等） |

## 三层模型

```
┌─────────────────────────┐    ┌──────────────────────────┐
│  Launcher (Python)      │    │  Repo (HTTP 静态目录)    │
│  · 进程管理与界面       │    │  index.json              │
│  · 应用商店与安装卸载   │    │  packages/<id>-<ver>.zip │
│  · OTA 自更新           │    │  launcher-<ver>.zip      │
└───────┬─────────────────┘    └───────────▲──────────────┘
        │ subprocess.Popen               │ publish.py
        ▼                                │
┌─────────────────────────┐              │
│  Apps (任意语言)        │ ─────────────┘
│  apps/ 递归扫描 app.json│
└─────────────────────────┘
```

- **Launcher**：spawn / 就绪探测 / 停止应用，管理商店、布局、更新
- **Apps**：`apps/**` 下含 `app.json` 即被注册，与语言无关
- **Repo**：远端静态目录，`publish.py` 把应用打成 zip 并更新 `index.json`

## 目录结构

```
web-launcher/
├── launcher.py              # 薄壳入口
├── launcher/                # 10 个功能模块
│   ├── config.py            # 配置加载 / 路径常量 / 工具函数
│   ├── app_registry.py      # 应用扫描 / 注册表 / group 推导
│   ├── process_manager.py   # spawn / 端口就绪 / close
│   ├── app_operations.py    # 安装 / 卸载
│   ├── repo.py              # 仓库索引 / HTTP 客户端
│   ├── zipio.py             # 原子解压工具
│   ├── http_handler.py      # HTTP 路由
│   ├── frontend.py          # 首页 HTML 渲染
│   ├── layout.py            # 用户布局覆盖（layout.json）
│   └── updater.py           # 二进制 OTA 替换脚本
├── publish.py               # 发布到仓库
├── config.json              # launcher / 仓库 / 发布配置
└── apps/                    # system / user 等应用目录
```

模块间按职责分层：`config` 提供常量，`app_registry` 扫描注册，`process_manager` 管进程，`app_operations` 管安装，`http_handler`/`frontend` 负责对外，`repo`+`zipio` 负责拉取与解压，`updater` 负责 OTA。

## 运行流程

1. 启动：读 `config.json` → `reload_apps()` 扫描注册表 → 监听 `127.0.0.1` HTTP 端口
2. 打开应用：`/api/open` 解析 `cmd`（`.py` 自动前缀解释器）→ `Popen` → TCP 端口轮询就绪 → 返回 iframe URL
3. 关闭应用：`p.terminate()` → 等 2s → 兜底杀整棵进程树
4. 安装：从仓库下载 zip → sha256 校验 → 原子解压到 `apps/<group>/<id>` → 重扫注册表
