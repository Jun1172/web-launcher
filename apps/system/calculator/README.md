# 🧮 科学计算器（calculator）

验证 Launcher 承载纯前端（无后端逻辑）应用的能力，以及双模式交互体验。

## 应用行为
- 启动 Python HTTP Server 仅提供静态 HTML/JS/CSS 页面
- 前端实现普通四则运算与程序员常用的 Hex/Dec/Oct/Bin 进制转换及位运算
- 所有计算均在浏览器本地完成，无后端 API 交互

## 验证什么
| 能力 | 实际行为 |
| --- | --- |
| 纯前端应用承载 | `app.py` 仅返回 HTML，无 `/api/*` 接口，Launcher 通过端口探测标记为 `ready` |
| 双模式切换 | 点击顶部 Tab 可无缝切换普通模式与程序员模式，UI 自适应 |
| 进制实时转换 | 程序员模式下输入数字，副屏实时显示 HEX/DEC/OCT/BIN 结果 |

## 适用场景
- 验证 Launcher 对轻量级纯 Web 应用的兼容性
- 作为无后端依赖应用的模板参考

## 验证步骤
1. 在 Launcher 中点击  科学计算器。
2. 切换到「程序员」模式，输入 `255`，观察副屏是否显示 `HEX:FF DEC:255 OCT:377 BIN:11111111`。
3. 切换回「普通」模式，测试 `12 × 8 ÷ 4`，结果应为 `24`。

## 文件
- `app.json` —— 应用清单（端口 8140）
- `app.py` —— 极简 HTTP Server，仅返回 HTML
