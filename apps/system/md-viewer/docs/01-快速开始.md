# 快速开始

## 环境要求

- Python 3.8 或更高
- **无第三方依赖**（仅用标准库即可运行）
- WebView2 Runtime：Windows 桌面窗口模式需要，Win10/11 一般自带

## 启动 launcher

```bash
python launcher.py
```

启动后：

- 若安装了桌面窗口依赖，自动以桌面窗口模式打开
- 否则浏览器访问 `http://127.0.0.1:8000/`

## 打开一个应用

1. 在桌面点击任意应用图标，或点状态栏的 🛒 应用商店安装新应用
2. 应用以 `iframe` 内嵌展示，运行中的进程由 launcher 统一管理
3. 应用一般自持 HTTP 服务；launcher 用 TCP 端口探测确认其就绪后才标记为可打开
