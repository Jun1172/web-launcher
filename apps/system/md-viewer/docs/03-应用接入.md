# 应用接入

每个应用目录至少包含一个 `app.json`，目录名即应用 `id`。launcher 递归扫描 `apps/**/app.json` 注册应用。

## app.json 字段

| 字段 | 类型 | 必填 | 默认 | 用途 |
|------|------|------|------|------|
| `id` | string | ✅ | — | 唯一标识，须与目录名一致 |
| `name` | string | ✅ | — | 显示名称 |
| `version` | string | ✅ | — | 语义化版本号 `1.0.0` |
| `cmd` | string[] | ❌ | — | 启动命令 |
| `port` | int | ❌ | — | TCP 就绪探测 + iframe URL 端口 |
| `icon` | string | ❌ | 📦 | emoji 图标 |
| `color` | string | ❌ | #999 | 主题色 |
| `changelog` | string | ❌ | — | 版本说明 |
| `released` | string | ❌ | — | 发布时间（ISO 8601） |
| `dock` | bool | ❌ | false | 是否常驻底部 Dock（可被 layout.json 覆盖） |
| `group` | string | ❌ | `"user"` | 分组来源；唯一决定归类 |
| `standalone` | bool | ❌ | false | 完全独立部署：runtime 打进应用包，不依赖全局环境 |
| `protect` | bool | ❌ | false | 源码保护：`.py` 编译为 `.pyc`，包内不含源码 |
| `deps` | string[] | ❌ | — | Python 依赖声明（如 `["paramiko", "numpy>=1.24"]`） |
| `exclude` | string[] | ❌ | — | 打包排除目录（如 `["cpp", "wrapper"]`） |

示例：

```json
{
  "id": "my-app",
  "name": "我的应用",
  "version": "1.0.0",
  "cmd": ["apps/user/my-app/app.py"],
  "port": 8120,
  "dock": false,
  "group": "user"
}
```

`cmd` 不支持外部依赖、路径穿越；`port` 缺省时启动即视为就绪（适用于无 HTTP 服务的后台进程）。

## 应用分类与分组

`group` 是**唯一判定来源**：

| 分组 | 行为 |
|------|------|
| `system` | 默认安装、接受更新、**不可卸载**（受保护分组） |
| `user` | 可安装 / 卸载（默认值） |
| 自定义（如 `business` / `admin`） | 发布与卸载按此分组 |

> `system` 旧字段已废弃，不再生效；只认 `group`。

外部应用仓库可按组把目录复制 / 软链到 launcher 的 `apps/` 下，但不要覆盖系统应用目录，也不要在同一 id 下放多个应用。

## 多语言启动 `cmd`

| 类型 | 处理方式 |
|------|----------|
| `.py` / `.pyw` | 自动前缀 Python 解释器（`sys.executable` / 打包态用系统 `python`） |
| `.exe` / ELF / 可执行文件 | 直接执行 |
| 无 `cmd` | 视为纯占位 stub，不拉起进程 |

参数中的相对路径会相对 launcher 根目录解析。

## C/C++ 应用模板（cpp-hello）

参照 `apps/user/cpp-hello/`：源码 + `build.{bat,sh}` + `run.py` 启动包装 + `app.json`。

- `run.py` 作为 Python 包装进程被 launcher 感知，可观测、可停止
- 关闭时用 `taskkill /T /F`（Win）或 `killpg`（POSIX）递归杀整棵树，子进程不会成孤儿
- 需针对目标 OS / CPU 架构分别编译

## standalone 应用（完全独立部署）

默认情况下，所有 Python 应用共享 launcher 的全局 runtime（`runtime/win-x64/`）。对于需要完全独立部署的应用，可在 `app.json` 声明 `standalone: true`：

```json
{
  "id": "critical-app",
  "name": "关键业务应用",
  "version": "1.0.0",
  "standalone": true,
  "cmd": ["app.py"],
  "port": 8120
}
```

**standalone 应用特点：**
- runtime 打进应用 zip，安装后存放在 `apps/<group>/<id>/runtime/`
- 不依赖全局 runtime，下载即用
- 不同应用可用不同 Python 版本
- 体积增加约 38MB（适合关键业务应用）

**适用场景：**

| 应用类型 | standalone | 理由 |
|---------|-----------|------|
| 系统应用（store、settings） | `false` | 跟 launcher 一起预装，共享 runtime |
| 小工具（hello、todo） | `false` | 体积小，不值得带 runtime |
| 关键业务应用 | `true` | 隔离环境，避免全局 runtime 损坏影响业务 |
| 需要特定 Python 版本的应用 | `true` | 如必须用 3.11 的 numpy 兼容性 |

## 源码保护（protect）

声明 `protect: true` 的应用，发布时会自动去源码化：

- `.py` 编译为 `.pyc`（包内无业务源码）
- 入口生成几行 runpy 启动器
- `cmd` 保持原样，与未保护应用同构

**注意：** pyc 绑定 Python 大版本，发布机的 Python 大版本需与部署机一致。
