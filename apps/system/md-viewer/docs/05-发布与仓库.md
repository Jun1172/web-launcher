# 发布与仓库

## 发布应用

`publish.py`（仓库根目录）负责把 `apps/` 下的应用打包、计算校验值，并上传到远端仓库 / 更新 `index.json`（发布脚本在仓库根目录手动运行）。

```bash
# 列出所有可发布的应用
python publish.py --list

# 发布单个应用（--dry-run 只打包不上传，用于测试）
python publish.py apps/user/my-app --dry-run
python publish.py apps/user/my-app

# 一键发布所有应用
python publish.py --all

# 只发某类 / 某分组
python publish.py --group business
```

发布流程：

1. 按 `app.json` 递归发现应用
2. 以 `group` 字段判定归类
3. 打成 `<id>-<version>.zip`，记录包体大小与 `sha256`
4. 如果声明 `deps`，自动下载依赖 wheels 并上传到 `/wheels/<平台>/`
5. 如果声明 `standalone: true`，runtime 打进应用包（增加约 38MB）
6. 生成 / 更新远端 `index.json` 中的条目

## app 条目白名单

写入 `index.json` 的字段被严格白名单约束，只保留实际生效的字段：

```
id / name / icon / color / version / changelog
port / cmd / dock / group / released
standalone / protect  # 新增
```

其余（旧的 `ready_check` / `workdir` / `stop_signal` / `stop_timeout` / `restart_policy` / `requires` 等）**已从 schema 移除**，不再声明，也不会写入索引。

## standalone 应用打包

声明 `standalone: true` 的应用，打包时会：

1. 检查本仓库 `runtime/<platform>/` 是否存在
2. 把整个 runtime 目录打进应用 zip 的 `apps/<group>/<id>/runtime/<platform>/`
3. 安装后应用启动时优先使用自带 runtime

**打包体积对比：**

| standalone | 打包内容 | 体积增量 |
|------------|---------|---------|
| `false` | 应用代码 + deps wheels | ~1-10 MB |
| `true` | 应用代码 + deps + runtime | +38 MB |

## 源码保护（protect）

声明 `protect: true` 的应用：

- `.py` 编译为 `.pyc`，包内不含源码
- 入口生成 runpy 启动器（几行样板代码）
- `cmd` 保持 `.py` 形式，与未保护应用同构

**注意事项：**
- pyc 绑定 Python 大版本，发布时需确认与部署机 runtime 版本一致
- 发布 standalone 应用时，建议同时开启 `protect`，确保版本匹配

## 远端仓库结构

```
/var/www/repo/
├── index.json              # 应用清单 + launcher 元信息
└── packages/
    ├── hello-1.0.0.zip
    ├── weather-1.0.0.zip
    └── launcher-1.0.0.zip   # launcher 自更新包
```

`repo_get(path)` 支持 BASIC 认证与 SSL 校验开关。

## 安装 / 升级

- 从仓库下载 zip → 校验 `sha256` → 原子解压到 `apps/<group>/<id>`（`launcher/zipio.py` 的 `atomic_extract_zip`）
- 兼容三种 zip 结构：`apps/<group>/<id>/...`、`<id>/...`、扁平文件列表
- 安装 / 升级均取**最新版本**

## 发布 Launcher 自身更新

```bash
# 1. 修改 config.json 的 launcher.version（如 1.0.3）
# 2. 发布
python publish.py --launcher --changelog "修复 X，新增 Y"
```

> `launcher` 自更新应使用 launcher 仓库（web-launcher）的 `publish.py --launcher`。
