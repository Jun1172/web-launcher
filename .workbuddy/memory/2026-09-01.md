## RV1103 部署支持：修复局域网访问时 APP 打不开的问题

- 诊断：`/api/open` 返回的 iframe URL 硬编码 `http://127.0.0.1:{port}`，远程浏览器 iframe 指向访问者本机；且所有应用进程绑定 `127.0.0.1`，板子不接受局域网连接。
- 修复：
  - `launcher/http_handler.py`：`/api/open` 改为按请求头 `Host` 生成 iframe URL（去端口后拼应用端口）。
  - `launcher/__main__.py`：main() 里 `os.environ["APP_HOST"] = LAUNCHER_HOST`，Popen 继承环境传给子应用。
  - 13 个 app.py：`ThreadingHTTPServer(("127.0.0.1", PORT), ...)` → `(os.environ.get("APP_HOST", "127.0.0.1"), PORT)`；store/todo/clock/settings/calculator 补了 `import os`。桌面默认行为不变。
  - README「部署到嵌入式主板」补充局域网访问说明。
- 验证：模拟 `Host: 192.168.1.50:8000` 请求 `/api/open?id=hello` → 返回 `http://192.168.1.50:8122`，进程正常拉起；全部改动文件 py_compile 通过。
- 板端使用：`config.json` 的 `launcher.host` 改为 `0.0.0.0`（launcher + 所有子应用随之对局域网开放）。
- RV1103 结论：单核 A7、无 GPU/OpenGL，pywebview/Chromium/QtWebEngine 均不可用；launcher 自带回退纯 HTTP 模式，界面走外部浏览器（路线 A）。本地屏幕方案：NetSurf-fb（需无 JS 模板）或 Qt/LVGL 原生壳调 REST API。
