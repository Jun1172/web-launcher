# 界面与交互

launcher 提供仿移动端的桌面界面，所有资源内嵌，可离线运行。

![Web Launcher 桌面](images/桌面.png)

## 状态栏

顶部状态栏包含：

- 时钟 / 网络 / 电量
- 🗂️ **布局编辑**按钮
- ⚙️ **关于**按钮（带更新红点，显示当前版本，有新版本时闪烁）
- 右上角窗口控制按钮（关闭 / 最大化 / 最小化）

## 桌面

- **分页桌面**：响应式网格，左右滑动切页，底部有分页指示器
- 应用图标：系统应用右上角带青色小圆点标记
- 点击图标打开应用（以 iframe 内嵌）

## Dock 栏

- 常驻底部，毛玻璃拟态，悬停上浮放大
- Dock 中存在度横向滚动，内容超出时可用滚轮 / 拖拽查看
- 哪些应用进 Dock 由 `dock` 字段与 `layout.json` 共同决定

## 手势

- 水平滑动：切换分页
- 垂直上滑：呼出最近任务面板
- 最近任务卡片：上滑清除、全部清除、点击切回应用
- 底部 Home 条：点击关闭面板

## 布局编辑（layout.json）

- 状态栏 🗂️ 打开「布局编辑」面板
- 可勾选每个应用是否在 Dock / 是否从桌面隐藏
- `layout.json` 覆盖 `app.json` 的 `dock` 默认值；未保存过时用默认
- 保存后立即 `reload_apps()` 刷新注册表

## 窗口行为

- 普通窗口带标题栏；最大化时切换为无框全屏
- 支持 via Ctrl+滚轮 / 快捷键缩放内容
- 纯浏览器（无桌面窗口时）：直接访问 `http://127.0.0.1:8000/`

## 相关配置

`config.json` 集中管理 launcher / 仓库 / 发布配置，避免散落在代码里。
