# 自更新与部署

## Launcher 自更新（双模式 OTA）

`/api/launcher/update` 触发后，用 `getattr(sys, "frozen", False)` 区分两种模式：

**源码模式（开发 / 非打包）**

1. 下载 `launcher-<ver>.zip`
2. 解压覆盖 `launcher.py` / `launcher/` 包
3. 合并 `config.json`
4. reload 生效

**编译模式（PyInstaller 打包）**

1. 下载二进制 → 校验 sha256
2. `updater.launch_self_update()` 后台 spawn `updater.bat`（Win）/ `updater.sh`（Linux）
3. 主进程退出 → 脚本替换 exe → 自动重启

状态栏右上角 ⚙️ 按钮显示版本号，有新版本时红点闪烁，点击「立即更新」即可 OTA。

## 安全注意事项

- launcher 默认只监听 `127.0.0.1`，**不对外暴露**
- 需要远程访问时：加反向代理 + 鉴权
- 仓库可用 HTTPS + BASIC 认证（`config.json.repo.auth`）+ SSL 校验开关
- 敏感配置（如 `env`）不进远端 `index.json`，防止密钥泄漏
- `/api/apps` 不暴露 env 内容

## 嵌入式部署

### Python 环境

- 推荐 Python 3.10+（兼容性最好）
- 树莓派 / Jetson：用系统自带 `python3` 即可
- 极小设备：`python3-minimal` + 手动补 `pip`

### 跨平台注意

- **ARM**：launcher 纯 Python 无架构依赖；C/C++ 应用需对应架构编译（建议静态链接）
- **Windows CE / RT**：不支持（依赖 `subprocess.CREATE_NO_WINDOW`）
- **Linux musl**：POSIX 信号可用，`CTRL_BREAK_EVENT` 不可用
- 分发 `dist/launcher.exe` 时，需把 `apps/` 与 `config.json` 放在 exe 同级

### 应用预装

- `apps/system/` 全部预装到主板（出厂默认）
- `apps/user/` 由用户后续通过应用商店安装
- 仓库 URL 配置成自己的镜像（HTTPS + basic auth 可选）
