# 🎮 2048

![界面预览](images/screenshot.png)

经典 2048 小游戏 demo，验证复杂游戏逻辑 + 键盘/触摸操作场景。

## 玩法
- 4×4 网格，每次移动所有方块朝指定方向滑动
- 相同数字的方块碰撞时合并，数值翻倍
- 达到 2048 获胜（可继续玩）
- 没有可行移动时游戏结束

## 操作
- **键盘**：方向键 / WASD
- **触摸**：在棋盘上滑动

## 功能
- 实时分数 + 历史最高分（存于 `localStorage`）
- 胜利提示 + 失败提示
- 新游戏按钮

## 验证什么
1. 复杂前端逻辑（矩阵旋转、合并算法）
2. 键盘事件 + 触摸事件处理
3. CSS 动态定位（calc 计算）
4. `localStorage` 持久化最高分

## 文件
- `app.json` —— 应用清单
- `app.py` —— 单文件 HTTP 服务（HTML/CSS/JS 内联）
