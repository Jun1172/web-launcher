📖 项目介绍

Web Launcher 是一个基于 Python 标准库 的轻量级应用运行时，支持部署 Python / C/C++ / Web 等多种类型的应用。核心价值：用最小依赖 + 一个 app.json 协议，即可对任意语言的应用做部署、增删、升级。

🎯 1.1.0 版本更新

  • ✅ 新增 standalone 字段，支持应用完全独立部署
  • ✅ runtime 打进应用包，不依赖全局环境
  • ✅ 不同应用可用不同 Python 版本
  • ✅ 混合模式：轻量应用共享 runtime，关键应用独立部署

📦 app.json 配置字段

字段 类型 必填 默认 说明
id string ✅ — 唯一标识，与目录名一致
name string ✅ — 显示名称
version string ✅ — 语义化版本号
cmd string[] ❌ — 启动命令
port int ❌ — TCP 就绪探测端口
standalone bool 新增 false runtime 打进应用包，完全独立部署
protect bool ❌ false .py 编译为 .pyc，源码保护
deps string[] ❌ — Python 依赖声明
group string ❌ "user" 分组：system / user / 自定义

🧬 standalone 应用（完全独立部署）

默认情况下，所有 Python 应用共享 launcher 的全局 runtime。对于需要完全独立部署的应用，可声明 standalone: true。

应用类型 standalone 理由
系统应用（store、settings） false 跟 launcher 一起预装，共享 runtime
小工具（hello、todo） false 体积小，不值得带 runtime
关键业务应用 true 隔离环境，避免全局 runtime 损坏
需特定 Python 版本 true 版本控制，避免兼容性问题

🚀 发布流程

📦 发布命令

# 列出所有可发布的应用
python publish.py --list

# 发布单个应用
python publish.py apps/user/my-app

# 一键发布所有应用
python publish.py --all

# 发布 launcher 更新
python publish.py --launcher --changelog "新增 standalone 支持"

🎯 打包体积对比

standalone 打包内容 体积增量
false 应用代码 + deps ~1-10 MB
true 应用代码 + deps + runtime +38 MB

🏗️ 项目架构

web-launcher/
├── launcher.py              # 主入口
├── launcher/                # 核心模块（14个文件）
│   ├── process_manager.py   # 进程启动/端口分配/清理
│   ├── app_registry.py      # 应用扫描/注册表
│   ├── deps_installer.py    # 依赖自动安装
│   └── ...
├── apps/
│   ├── system/              # 系统应用（不可卸载）
│   │   ├── store/           # 应用商店
│   │   ├── settings/        # 设置页面
│   │   └── md-viewer/       # 说明书中心
│   ├── user/                # 用户应用
│   └── etws/                # 业务应用（自定义分组）
├── runtime/win-x64/         # 内嵌 Python 3.11
├── wheels/win-x64/          # 离线依赖缓存
└── tools/                   # 开发工具
    ├── toolbox.py           # 统一工具箱
    ├── package.py           # 打包 exe
    └── make_runtime.py      # 构建 runtime
