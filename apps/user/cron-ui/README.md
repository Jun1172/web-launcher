# ⏱️ 可视化定时任务（cron-ui）

一个内嵌式的可视化 Cron 定时任务管理应用，纯 Python + 内嵌 HTML 实现，无外部依赖、离线可用。

## 功能

- **可视化 Cron 生成器**：5 个下拉框（分/时/日/月/周），支持 `*`、`*/N`、具体值、区间 `A-B`、列表 `A,B,C`，实时生成表达式并显示人类可读描述（如"每天凌晨2点"）。
- **任务管理**：卡片式列表，支持新建/编辑/删除/启停。
- **内存调度器**：后台线程每秒检查，分钟级触发，自动执行匹配任务。
- **手动触发**：点击"运行"按钮立即执行一次，弹窗显示退出码与输出。
- **执行日志**：每个任务保留最近 50 条记录（时间、退出码、输出摘要），点击卡片可展开查看。
- **下次执行时间**：前端 JS 逐分钟扫描计算并显示。
- **Windows 隐藏窗口**：`subprocess` 使用 `CREATE_NO_WINDOW`，不弹出黑框。

## 端口

默认 `8152`，由 `LAUNCHER_APP_PORT` 环境变量覆盖。

## 任务存储

`tasks.json`（与 `app.py` 同目录），JSON 字典结构，进程重启后自动加载。

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET  | `/` | 返回内嵌 HTML 首页 |
| GET  | `/api/tasks` | 返回所有任务列表 |
| POST | `/api/tasks` | 创建任务（body: `{name, cron, command, enabled}`） |
| POST | `/api/tasks/{id}/update` | 更新任务字段 |
| POST | `/api/tasks/{id}/delete` | 删除任务 |
| POST | `/api/tasks/{id}/run` | 手动触发执行一次 |
| GET  | `/api/tasks/{id}/logs` | 获取任务执行日志 |

## 文件

- `app.json` —— 应用清单
- `app.py` —— 单文件 HTTP 服务（后端 + 内嵌 HTML 前端）
- `tasks.json` —— 任务数据（运行后自动生成）
